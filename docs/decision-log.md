- **템플릿 방식**: 규칙은 `CLAUDE.md` 한 파일에 모으고, 그게 `sync-standards.sh`·`/start-project` 스킬을 타고 다른 프로젝트로 전파된다. (별도 배선 최소화)
- **적용 경로 3가지**: ① 글로벌 `~/.claude/CLAUDE.md`(자동) ② `/start-project` 스킬 ③ GitHub "Use this template". (README 참고)
- **repo 공개**: `newWork`은 public → raw URL / sync-standards가 어디서든 동작. (비밀정보 없음)
- **환경 이해**: 웹/모바일(아이패드)은 임시환경이라 `~/.claude/` 미유지 → 지속시키려면 **repo에 커밋**해야 함.
